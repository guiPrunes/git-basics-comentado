## Comandos desta seção (2)

### 1. `git init [nome-do-projeto]`

```bash
git init [nome-do-projeto]
```

Inicializa um repositório na pasta local onde o comando foi rodado (via terminal)

> Tenha cuidado ao utilizar esse comando, pois cria uma cópia de todos os arquivos para versionamento, então se criar em alguma pasta raiz, vai te dar problemas.

---

### 2. `git clone [url]`

```bash
git clone [url]
```

Clona um repositório via link do GitHub, faz uma cópia de todos os arquivos.

> Se você clonar um repositório dentro de uma pasta, ele vai criar uma pasta dentro da pasta. Então acredito que seja legal clonar o repositório justamente aonde ele deve ficar.

---
