## Itens desta seção (3)

### 1. GitHub para Windows

<https://windows.github.com>

Instalador do aplicativo da plataforma GitHub para sistemas operacionais Windows. 
>  Traz a ideia de simplificar o ambiente de desenvolvimento da plataforma sem utiliza-lá no navegador, trazendo interfaces diferentes e algumas features novas.

---

### 2. GitHub para Mac

<https://mac.github.com>

Instalador do aplicativo da plataforma GitHub para Sistemas Operacionais MacOS.  

>  Difere do modelo de instalação do Windows, por se tratar de um sistema operacional diferente. Aparentemente se mantém no mesmo esquema do Windows.

---

### 3. Git para todas as plataformas

<https://git-scm.com>

Instalador da ferramenta de versionamento Git para Sistemas Operacionais Windows/MacOs.
> O página reconhece o Sistema Operacional do usuário e já redireciona a última versão do instalador para o sistema.
